# audit-log-integrity-java

基于 Spring Boot 的本地审计日志采集、完整性校验与保留示例工程。

- 多来源事件归一化：字段别名映射；缺失/非法输入带可区分原因拒绝；重复 eventId 幂等不重复入库
- 哈希链顺序追加：并发下编号连续、不重不漏；改写、删除、中途插入、非法行均可检测并定位
- 保留期管理：到期前缀剪切归档（ARCHIVE）或归档后删除（DELETE），锚点保证清理后结论仍可解释
- 合规查询：按时间/主体/来源/动作/结果过滤，显式披露已扫描段与不可得段

详细语义与本地验证方法见 [docs/audit-log.md](docs/audit-log.md)。

快速验证：

```bash
mvn test -o
```
